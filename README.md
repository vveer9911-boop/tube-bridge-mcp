# tube-bridge MCP Server

Cloud-hosted Remote MCP Server for YouTube Search, Metadata, Transcripts, and Frame Extraction.

## Endpoints
- `/health` - Health check endpoint
- `/mcp` - Streamable HTTP MCP endpoint for ChatGPT Custom Connectors
- `/sse` - Legacy SSE MCP endpoint
